# HTML Practical - John

## Before you submit
1. Open each `task*.html` file in Chrome/Firefox and check it renders correctly.
2. Replace the roll number placeholder in `task1.html`'s `<title>`.
3. Replace the placeholder files with real media:
   - `assets/video/myvideo.mp4` and `myvideo.webm`
   - `assets/audio/myaudio.mp3`
   - `assets/docs/sample.pdf`
   (see the README.txt in each assets subfolder)
4. Read through every file and be ready to explain any line — you may be
   asked to during evaluation.

## Files
- task1.html – Basic HTML structure
- task2.html – Text formatting
- task3.html – Lists
- task4.html – Links and images
- task5.html – Table / timetable
- task6.html – Registration form
- task7.html – Semantic HTML
- task8.html – Embedded media (Media Hub)
- index.html / about.html / contact.html – Mini portfolio project (Task 9)
- style.css – Shared stylesheet for the portfolio pages
- assets/ – Images, and placeholders for video/audio/PDF

## Publishing to GitHub
```bash
cd webproject
git init
git add .
git commit -m "Complete HTML practical tasks 1-9"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo>.git
git push -u origin main
```
Then follow your instructor's exact submission steps (e.g. submitting the
repo link, or enabling GitHub Pages) as given at the end of the practical
document.
